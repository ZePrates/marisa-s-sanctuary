# Marisa's Sanctuary

Cria uma landing page “Link na Bio” premium, minimalista, elegante e acolhedora, destinada a uma Psicóloga Clínica e da Saúde, para ser utilizada como link principal na biografia do Instagram.

A página deve funcionar como uma alternativa personalizada ao Linktree.

CONCEITO

A experiência deve transmitir:

segurança

calma

acolhimento

proximidade

profissionalismo

simplicidade

O design deve ter uma estética feminina, contemporânea, sofisticada e terapêutica, sem parecer demasiado clínica ou corporativa.

Não quero um template genérico de Linktree.

A página deve parecer uma extensão natural da identidade profissional de uma psicóloga.

PALETA DE CORES

Utilizar uma paleta muito suave baseada em:

Creme / off-white como fundo principal

Verde claro / verde sálvia como cor principal

Verde mais escuro e suave para texto

Tons intermédios muito discretos para borders e sombras

Sugestão inicial:

Fundo creme: #F7F3E8

Verde sálvia: #A8BFA8

Verde escuro: #526B59

Creme claro: #FCFAF4

Estas cores são apenas uma referência e podem ser ligeiramente ajustadas para criar uma combinação visual harmoniosa e garantir boa acessibilidade.

Não utilizar cores fortes, neon, azul, roxo ou gradientes.

ESTRUTURA

Criar uma única página vertical, mobile-first, pensada principalmente para pessoas que chegam através do Instagram.

1. FOTO DE PERFIL

No topo criar um espaço circular para a fotografia profissional da psicóloga.

Não gerar nem inventar uma fotografia.

Utilizar apenas um placeholder elegante que possa ser substituído posteriormente.

O espaço deve ter uma moldura muito subtil em verde sálvia.

2. NOME

Apresentar:

Marisa Isabel Valido dos Santos

Por baixo:

Psicóloga Clínica e da Saúde

O nome deve ter destaque visual.

Utilizar uma fonte serifada elegante e contemporânea para o nome.

3. FRASE PRINCIPAL

Apresentar em destaque:

“Um espaço seguro para parar, sentir e recomeçar.”

Esta é a principal mensagem emocional da página.

Deve ter uma presença visual forte, mas delicada.

4. FRASE SECUNDÁRIA

Por baixo, com menor tamanho:

“Onde cuidar de quem cuida, também importa.”

Criar bastante espaço entre os elementos para que a página respire.

Não transformar estas frases num bloco de texto.

5. DOIS LINKS

Criar exatamente dois links principais.

LINK 1

Marcar Consulta

Adicionar um pequeno ícone de calendário ou consulta, muito discreto.

O URL deve ficar facilmente editável posteriormente.

Não inventar ainda o URL de marcação.

LINK 2

Instagram

Adicionar o ícone do Instagram.

URL:

https://www.instagram.com/marisasantos.psicologa/

BOTÕES

Os dois botões devem ser visualmente semelhantes.

Características:

verde sálvia;

texto verde escuro;

cantos arredondados;

largura confortável;

altura suficiente para utilização em smartphone;

sombra muito subtil;

aparência elegante;

excelente área de toque;

transição suave ao passar o cursor.

Não utilizar botões com aspeto tecnológico ou demasiado pesado.

O botão “Marcar Consulta” pode ter ligeiramente mais destaque que o Instagram.

TIPOGRAFIA

Utilizar duas famílias tipográficas.

Para o nome e títulos

Uma serif elegante, suave e contemporânea.

Preferência por:

Cormorant Garamond

DM Serif Display

Playfair Display

Para restante conteúdo

Uma sans-serif moderna e limpa.

Preferência por:

Manrope

Lato

Inter

A combinação deve transmitir elegância sem parecer luxuosa ou distante.

ELEMENTOS GRÁFICOS

Manter o design minimalista.

Pode utilizar pequenas formas orgânicas muito subtis, mas não adicionar folhas, flores, desenhos de cérebro, símbolos de psicologia ou outros elementos clichê.

Não utilizar ilustrações genéricas de bancos de imagens.

A identidade visual deverá assentar principalmente em:

tipografia + espaço + cor + formas suaves.

RODAPÉ

Adicionar discretamente:

Psicologia Clínica e da Saúde

E abaixo, em tamanho reduzido:

“Este espaço não substitui acompanhamento psicológico ou médico.”

RESPONSIVIDADE

A página deve ser desenvolvida com prioridade absoluta para smartphone.

Deve funcionar perfeitamente em:

iPhone

Android

tablets

desktop

No desktop, manter o conteúdo numa coluna central relativamente estreita, preservando a sensação de página pessoal/mobile.

Não criar uma página desktop demasiado larga.

ANIMAÇÕES

Utilizar apenas microanimações:

entrada suave dos elementos;

ligeiro hover nos botões;

transições suaves.

Sem parallax.

Sem animações exageradas.

Sem efeitos chamativos.

CONFIGURAÇÃO

Estruturar o código para que seja muito fácil alterar posteriormente:

fotografia;

nome;

título profissional;

frase principal;

frase secundária;

URL de marcação de consulta;

URL do Instagram.

Criar constantes/configuração centralizada sempre que possível.

SEO

Adicionar:

Title:
Marisa Isabel Valido dos Santos | Psicóloga Clínica e da Saúde

Description:
Um espaço seguro para parar, sentir e recomeçar. Psicologia Clínica e da Saúde.

Adicionar favicon e Open Graph metadata.

IMPORTANTE

Neste momento não existe fotografia disponível.

Não criar uma fotografia artificial.

Criar apenas o espaço reservado para a fotografia, que será substituída numa segunda fase.

Não adicionar:

outros links;

outras redes sociais;

newsletter;

blog;

testemunhos;

preços;

formulário;

menu;

publicidade;

banners;

funcionalidades desnecessárias.

O objetivo é uma página extremamente simples, bonita e profissional, onde a pessoa entra pelo Instagram e imediatamente encontra:

quem é a psicóloga → qual é a sua mensagem → como marcar consulta → Instagram.

O resultado final deve parecer uma landing page personalizada de uma marca profissional de Psicologia, e não um clone visual do Linktree.
